# Chart partials (`components/charts/`)

Heavy Apex snippets or reusable “chart organism” wrappers can live here when they are reused across pages.

Until then, shared chart **chrome** stays in [`components/analytics/chart-shell-card.php`](../analytics/chart-shell-card.php); page-local Apex options remain in view `<script>` blocks.

See **[docs/UI_COMPONENTS.md](../../../../docs/UI_COMPONENTS.md)** for the full catalogue and **[DESIGN_SYSTEM.md](../../../../DESIGN_SYSTEM.md)** for analytics/chart visuals and theme conventions.
